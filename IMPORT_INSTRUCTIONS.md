# Инструкция по импорту данных из XLSX в Firebase

## Подготовка

1. Убедитесь, что у вас есть права администратора для Firebase проекта
2. Убедитесь, что ваш XLSX файл готов к импорту:
   - Столбцы содержат правильные заголовки
   - Данные находятся в табличном формате
   - Даты имеют понятный формат (например, ГГГГ-ММ-ДД или любой формат, понятный Excel)

## Настройка аутентификации Firebase

Для выполнения импорта вам нужно настроить аутентификацию Firebase Admin SDK:

1. Зайдите в Firebase Console (https://console.firebase.google.com/)
2. Выберите ваш проект registry20prod
3. Перейдите в "Настройки проекта" → "Сервисные аккаунты"
4. Сгенерируйте новый ключ в формате JSON
5. Сохраните файл ключа в безопасное место
6. Установите переменную окружения GOOGLE_APPLICATION_CREDENTIALS, указывающую на путь к файлу ключа:

### Windows:
```cmd
set GOOGLE_APPLICATION_CREDENTIALS="путь\к\вашему\ключевому\файлу.json"
```

### Альтернативный вариант (для разработки):
Если вы используете этот скрипт в том же проекте, вы можете использовать application default credentials:

```cmd
gcloud auth application-default login
```

## Запуск импорта

Скрипт поддерживает импорт в следующие коллекции:

- `finance` - финансовые записи
- `correspondent` - корреспонденты
- `transport` - транспортные данные
- `finance_categories` - категории финансов
- `household` - бытовые записи
- `vehicles` - транспортные средства
- `maintenance` - обслуживание транспортных средств

### Синтаксис команды:
```cmd
npm run import-xlsx <путь_к_xlsx_файлу> <название_листа> <тип_данных>
```

### Примеры:

1. Импорт финансовых данных:
```cmd
npm run import-xlsx ./data.xlsx "Sheet1" finance
```

2. Импорт категорий:
```cmd
npm run import-xlsx ./categories.xlsx "Categories" category
```

3. Импорт транспортных средств:
```cmd
npm run import-xlsx ./vehicles.xlsx "Vehicles" vehicle
```

## Форматы данных

Скрипт ожидает определенные заголовки столбцов для правильного сопоставления данных. Ниже приведены возможные заголовки для каждого типа:

### Finance:
- `date` или `Date` - дата (в формате ГГГГ-ММ-ДД)
- `name` или `Name` или `description` - название
- `price` или `Price` или `cost` - цена
- `quantity` или `Quantity` - количество
- `total` или `Total` - итого
- `classification` или `Classification` или `category` - классификация
- `comment` или `Comment` или `notes` - комментарий

### Vehicle:
- `vehicleNumber` или `VehicleNumber` или `number` - номер транспортного средства
- `type` или `Type` или `vehicleType` - тип
- `make` или `Make` или `brand` - марка
- `model` или `Model` - модель
- `year` или `Year` - год
- `vin` или `VIN` - VIN
- `registrationDate` или `RegistrationDate` - дата регистрации
- `insuranceExpiry` или `InsuranceExpiry` - дата окончания страховки

И другие аналогично для остальных типов.

## Важные замечания

1. Скрипт будет добавлять новые записи, не проверяя на дубликаты
2. Убедитесь, что у вас достаточно квоты для записи в Firestore
3. Импорт может занять некоторое время в зависимости от объема данных
4. Скрипт выводит информацию о процессе импорта
5. В случае ошибки импорт остановится на этой записи, но продолжит с следующей

## Безопасность

Не коммитите ключевые файлы в репозиторий. Добавьте соответствующие файлы в .gitignore.
