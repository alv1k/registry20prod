# Приложение Sample Table

Это приложение с таблицами-примерами, созданное с использованием React, TypeScript и Firebase.

## Возможности
- Управление финансовыми записями
- Управление транспортными записями
- Управление записями корреспондентов
- Визуализация данных с помощью диаграмм
- Адаптивный дизайн для мобильных устройств и настольных компьютеров
- Контроль доступа на основе ролей (администратор/не администратор)

## Инструкции по настройке

1. Клонируйте репозиторий
2. Установите зависимости: `npm install`
3. Настройте проект Firebase
4. Настройте переменные окружения (см. `.env.example`)
5. Разверните в Firebase: `npm run deploy`

## Доступные скрипты

- `npm start` - Запустить сервер разработки
- `npm test` - Запустить тесты
- `npm run build` - Сборка для продакшена
- `npm run eject` - Открепиться от Create React App
- `npm run deploy` - Развертывание в Firebase

## Используемые технологии

- React с TypeScript
- Firebase (Firestore, Аутентификация, Функции)
- Tailwind CSS для стилизации
- Recharts для визуализации данных
- Zustand для управления состоянием

# Sample Table Application

This is a sample table application built with React, TypeScript, and Firebase.

## Features
- Financial record management
- Transport record management
- Data visualization with charts
- Responsive design for mobile and desktop
- Role-based access control (admin/non-admin users)

## Setup Instructions

1. Clone the repository
2. Install dependencies: `npm install`
3. Set up Firebase project
4. Configure environment variables (see `.env.example`)
5. Deploy to Firebase: `npm run deploy`

## Available Scripts

- `npm start` - Run development server
- `npm test` - Run tests
- `npm run build` - Build for production
- `npm run eject` - Eject from Create React App
- `npm run deploy` - Deploy to Firebase

## Technologies Used

- React with TypeScript
- Firebase (Firestore, Authentication, Functions)
- Tailwind CSS for styling
- Recharts for data visualization
- Zustand for state management
